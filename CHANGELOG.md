# Histórico de versões

## 1.2.1 — Estrutura reorganizada

- separação do site na pasta `frontend/`;
- manutenção da API na pasta `apps-script/`;
- documentação centralizada em `docs/`;
- workflow atualizado para gerar dados dentro de `frontend/dados/`;
- publicação do conteúdo de `frontend/` na raiz do GitHub Pages;
- inclusão de guia indicando quando é necessária nova implantação do Apps Script;
- nenhuma alteração funcional no Apps Script.

## 1.2.0 — Clientes, contatos e histórico

- seleção de contatos vinculados ao cliente;
- preenchimento automático de dados do contato;
- histórico local de orçamentos;
- pesquisa, abertura, duplicação e exclusão;
- módulo dedicado de impressão/PDF.
